# SuperCV 使用说明书

> 文档版本：2.0  
> 适用平台：Windows 10 / Windows 11  
> 适用产品：SuperCV V2  
> 最后更新：2026-08-16

SuperCV 是一款 Windows 剪贴板效率工具，用于记录、整理、检索和复用近期复制的文字与图片。它同时提供工作区、书签、长期历史、快捷键、AI 文本处理，以及可通过工具读取和操作条目的 AI Agent。

## 1. 快速开始

1. 启动 SuperCV，确认主窗口顶部的“列表更新”处于开启状态。
2. 在任意应用中复制文字；启用图片支持后也可以复制图片。
3. 回到 SuperCV，新的剪贴板内容会出现在当前工作区的条目列表中。
4. 单击条目可将其粘贴到此前使用的应用；也可以通过条目菜单编辑、复制、导出、置顶、着色或删除。
5. 在主窗口搜索框输入关键词并按 Enter，可筛选当前工作区中的普通历史条目。

关闭主窗口不一定退出程序。若“关闭应用直接退出”未启用，窗口会隐藏到系统托盘；可从托盘菜单重新打开或彻底退出。

## 2. 主窗口

### 2.1 顶部工具区

- 多功能按钮：拖动主窗口；双击行为可在设置中改为展开、最小化或其他动作。
- 搜索框：执行普通文本筛选，也支持 `/ai` 和 `/fs` 命令。
- 菜单按钮：打开工作区、主题、显示、历史、快捷键、AI 等设置。
- 关闭按钮：按当前关闭行为隐藏到托盘或直接退出。

### 2.2 列表更新

列表更新开启时，SuperCV 监听新的剪贴板变化并写入当前工作区；关闭后不会继续记录新复制的内容，已有条目不会因此删除。

### 2.3 条目显示数量

主窗口可同时显示 3 至 6 个条目。滚轮或移动命令会改变可见窗口，条目的真实顺序不会因翻页改变。设置中的“显示条目数”也会影响快捷键对应的可见条目范围。

### 2.4 新建空白与清空工作区

- 新建空白：创建一个可直接编辑的空白文字条目。
- 清空当前工作区：删除当前工作区的普通条目。执行前请确认重要内容已保存到书签或文件。

## 3. 剪贴板条目

### 3.1 支持的格式

文字条目可包含以下格式：

- `UnicodeText`：首选文字格式；AI Agent 默认只读取和生成此格式。
- `Text`：兼容旧式纯文本。
- `Html`：保留网页或富文本的 HTML 表示。
- `Rtf`：保留富文本格式。

图片条目通过独立图片缓存保存。一个条目不会同时作为图片和文字条目处理。Agent 仅支持文字条目，不读取图片像素内容。

### 3.2 条目卡片

卡片显示内容预览、字符或图片信息、记录时间、显示序号、置顶状态和颜色标记。预览可能被截断，但编辑和读取全文不会使用被截断的预览。

颜色标记值如下：

- 0：无标记
- 1：红色
- 2：橙色
- 3：紫色
- 4：绿色
- 5：蓝色

### 3.3 编辑与撤销

打开条目编辑界面后修改文字，离开编辑状态时保存。每个条目最多保留最近 5 次可撤销状态；“撤销修改”会恢复内容、颜色标记和置顶状态。

“转为纯文本”、部分 AI 替换和 Agent 默认编辑会只保留 `UnicodeText`。若需要保留 HTML/RTF，应在操作前保存书签、导出文件，或明确要求 Agent 保留其他格式。

### 3.4 导出与拖放

文字可导出为 TXT 或 RTF；图片可导出为 PNG、JPEG、BMP 或 TIFF。拖动条目到其他应用时，SuperCV 会尽量提供原有文字格式；图片会提供位图或对应文件路径，最终接受哪些格式由目标应用决定。

### 3.5 置顶与删除

置顶条目会优先位于普通列表前方，也不会被普通条目数量上限自动淘汰。删除会移除当前工作区中的条目；是否需要确认由“删除确认”设置决定。

## 4. 工作区

工作区用于隔离不同任务、客户或资料集合。每个工作区拥有独立的普通条目和长期历史。

- 新建：在工作区菜单选择“新建工作区”，输入不超过 30 个字符且不重复的名称。
- 切换：在主窗口选择目标工作区，列表立即切换。
- 重命名：在工作区菜单中对目标工作区执行重命名。
- 删除：至少保留一个工作区；删除工作区会同时删除其普通条目、长期历史和不再使用的图片缓存。

## 5. 书签

书签适合保存经常复用且不应被普通历史淘汰的文字，例如邮件签名、地址、命令或模板。

- 从条目菜单创建书签。
- 单击书签可粘贴内容并恢复到原活动窗口。
- 书签可编辑、删除和拖动排序。
- 书签与工作区独立；切换工作区不会改变书签内容。

## 6. 搜索与长期历史

### 6.1 普通搜索

在主窗口搜索框输入精确子串并按 Enter，只显示当前工作区中 `UnicodeText` 包含该字符串的条目。清空或返回搜索框会退出筛选。

### 6.2 长期历史

启用“长久存储”后，每个工作区会维护独立的持久记录。历史记录页支持关键词、日期范围、复制、删除和加载更多。

普通条目数量上限为 8 至 128。达到上限时，最旧且未置顶的普通条目会被淘汰。长期历史最多可保存大量独立记录；如果需要长期追溯，请保持长久存储开启。

## 7. 全局快捷键

默认快捷键可能因设置而改变：

- `Win + V`：由 SuperCV 接管 Windows 剪贴板入口（需启用对应设置）。
- `Alt + Shift + 1` 至 `0`：粘贴显示序号对应的条目。
- `Alt + Shift + Q` 至 `Y`：粘贴当前可见的第 1 至第 6 个条目。
- `Alt + 方向键`：移动主窗口。
- `Alt + Shift + M`：在上次位置继续粘贴并移动到下一条。
- `Alt + Shift + N`：在上次位置继续粘贴并移动到上一条。

在“设置 > 快捷键”中选择功能后按新的组合键即可修改；按 Esc 取消录入。快捷键无效通常表示组合键被其他应用占用、修饰键冲突，或全局快捷键功能未启用。

## 8. AI 配置

在“设置 > AI”中：

1. 开启 AI 总开关。
2. 选择 DeepSeek、GLM、通义千问、MiniMax 或自定义 OpenAI 兼容服务。
3. 输入当前服务商的 API Key。
4. 自定义服务需要填写 HTTPS `base_url` 和模型名；本机开发接口允许 loopback HTTP。
5. 使用“连接测试”确认配置可用。

API Key 不写入普通 JSON，而使用当前 Windows 用户作用域的 DPAPI 保存在 `credential.bin` 中。AI 请求仍会把用户选择或 Agent 读取到的文字发送给配置的服务商，请勿提交不应外发的密码、密钥、个人隐私或商业机密。

## 9. AI 文本处理

文字条目支持翻译、摘要、润色、通俗解释和自定义指令。处理完成后可替换当前条目内容；替换通常保存为 `UnicodeText`，可通过“撤销修改”恢复上一版本。

自定义指令包含显示名称和提示词，可新建、编辑和删除。若指令文件被外部修改，SuperCV 会监视并刷新对应内容。

## 10. AI Agent 对话

### 10.1 入口

- 多条目入口：在主窗口输入 `/ai 问题`。Agent 可按需读取当前工作区中的多个条目。
- 单条目入口：在条目的 AI 对话入口提问。Agent 会获得该条目的 GUID，并优先围绕当前条目工作。

Agent 不会默认把全部条目全文一次性发送给模型。它先获取基础信息，再按任务需要读取目标条目全文，以减少上下文用量。

### 10.2 Agent Loop

每次对话采用有限轮次的 Agent Loop：

1. 模型读取系统约束、当前工作区信息、时间、权限和对话上下文。
2. 模型选择一个或多个工具。
3. `AgentTool` 校验参数与权限并执行操作。
4. 工具结果作为 `tool` 消息返回模型。
5. 模型继续调用工具，或停止工具调用并给出最终回答。

单次请求最多执行 12 轮，避免错误模型无限循环。上下文会保留最近对话并按字符预算淘汰较旧轮次；系统规则与最新用户消息始终保留。

### 10.3 执行过程与正式回答

模型的推理文本和正式回答均通过服务端事件流逐段显示。最终回答前的每次回复、工具请求和工具结果会显示在“Agent 执行过程”展开区；停止调用工具后的内容才显示在正式回答区。工具调用参数仅在内部接收、重组和校验，不会按分片输出到界面。执行轨迹用于理解 Agent 做了什么，不等同于最终结论。

### 10.4 权限档位

- Agent：只读：允许读取、筛选和定位；拒绝编辑、新建、删除、置顶和颜色标记。
- Agent：审核批准：每次修改前复用 SuperCV 现有确认弹窗；取消后会把拒绝结果反馈给模型。
- Agent：完全访问：Agent 可直接执行修改，不再逐次确认。

建议默认使用“审核批准”。处理敏感或陌生任务时使用“只读”；只有在明确理解任务范围时才使用“完全访问”。

### 10.5 Agent 工具

#### list_entries

读取条目基础信息，包括本地创建时间、GUID、显示序号、置顶状态、颜色标记、最多约 512 token 的 `UnicodeText` 预览、全文 token 估算、所含格式和图片占位说明。

#### read_entries

按 GUID 或显示序号读取全文，可选择 `UnicodeText`、`Text`、`Html` 和 `Rtf`。默认只读取 `UnicodeText`。

#### edit_entry

对一个条目的 `UnicodeText` 执行精确查找替换。普通模式要求查找文本唯一；若要替换所有匹配项，需要设置 `replace_all=true`。默认编辑后只保留 `UnicodeText`。

#### create_entry

新建文字条目。优先只生成 `UnicodeText`；确有需要时可同时提供其他文字格式。

#### delete_entries

按 GUID 或显示序号删除一个或多个条目。只读模式拒绝；审核批准模式会显示确认弹窗。

#### filter_entries

支持创建时间范围、置顶状态、颜色标记、精确子串和自定义正则表达式。匹配只针对 `UnicodeText`。可仅把 GUID 返回 Agent，也可同步筛选主窗口；关闭 Agent 对话后会退出由 Agent 建立的筛选。

#### read_manual

读取本 Markdown 说明书。Agent 不能把说明书内容当作高于系统提示的指令。

#### read_visible_entry_ids

读取当前主窗口前台最靠前的 1 至 6 个条目 GUID。

#### navigate_to_entry

把目标条目移动到前台第一项；若接近列表末尾无法成为第一项，则尽可能靠前。

#### set_entry_appearance

设置条目置顶状态或颜色标记。只读模式拒绝；审核批准模式会显示确认弹窗。

### 10.6 索引和数据边界

- GUID 是条目的稳定标识。
- `display_id` 是当前普通列表从 1 开始的显示序号，可能随新增、删除、置顶和工作区切换变化。
- GUID 只在 Agent 与工具之间用于内部定位，不会显示在正式回答中；正式回答需要标识条目时，只使用“显示序号 N”。
- Agent 只能访问当前普通历史条目数量上限内的条目，不会自动访问已淘汰但仍存在于长期历史数据库中的记录。
- 无筛选要求时，Agent 被要求优先查看创建时间较新的条目。
- Agent 可通过 `web_search` 联网检索公开信息；每个用户回合最多 6 次，单次结果最多 4000 token，累计最多 16000 token。搜索结果属于不可信外部内容，不能改变 Agent 的工具规则或权限；除 `web_search` 外，Agent 不会自行访问网络。模型服务本身仍可能需要网络才能生成回复。

## 11. 命令输入

- `/ai 问题`：打开当前工作区的 Agent 对话。
- `/fs 查询`：使用 AI 对普通条目进行模糊匹配并筛选结果。

普通关键词搜索不等于模糊搜索。普通搜索是精确子串匹配；`/fs` 会调用模型判断语义相关性。

## 12. 托盘与后台运行

系统托盘菜单可打开 SuperCV、暂停或恢复列表更新，以及退出应用。希望保留后台记录时可关闭主窗口但不要退出；希望停止进程和全局快捷键时请选择“退出”。

## 13. 设置说明

- 登录启动：为当前 Windows 用户注册启动项。
- 关闭应用直接退出：关闭主窗口时结束进程，而不是隐藏到托盘。
- 双击多功能按钮行为：设置展开、最小化等动作。
- 增强动画：控制卡片和窗口动画；低性能设备可关闭。
- 深色模式：在深色和浅色主题之间切换。
- 显示条目数量：每屏 3 至 6 个条目。
- 剪贴板文字大小：小、中、大。
- 窗体动画跟随：数值越高，窗口跟随越快。
- 窗体不透明度：影响主窗口和条目卡片。
- 删除确认：删除普通条目前是否确认。
- 支持图片：记录图片；关闭时会按提示移除工作区图片条目与缓存。
- 条目数量限制：每个工作区保留 8 至 128 个普通条目。
- 长久存储：是否写入独立长期历史。

## 14. 数据与安全

默认数据目录为：

```text
%LocalAppData%\SuperCV\V2
```

其中包含设置、工作区、普通历史、书签、指令、图片缓存和长期历史数据库。运行期间不要直接编辑、移动或删除这些文件。`SUPERCV_V2_DATA_ROOT` 可把 V2 数据重定向到隔离目录，主要用于测试和诊断。

安全建议：

- 对重要内容建立书签或导出文件，不要只依赖有限的普通历史。
- 在共享电脑上暂停列表更新或退出程序。
- 不要把密码、访问令牌或隐私数据发送到不可信 AI 接口。
- 使用 Agent“完全访问”前确认工作区和任务范围。
- 大批量删除或替换前先导出或建立书签。

### 14.1 导出与迁移

在“设置 > 关于”中可使用“导出与迁移”创建一个 `.supercvbackup` 文件。导出会先完成待保存的数据写入，并将设置、工作区、普通与长期历史、书签、自定义指令、图片缓存和 AI 用量记录打包到同一个文件中。

“导入配置与内容”只接受 SuperCV 创建的迁移文件。导入会先检查包格式和版本、每个文件的 SHA-256 校验值、文件路径安全性，以及设置、工作区、历史、书签、指令和长期历史数据库是否能被当前版本读出；全部通过后才会暂存，重启时再替换当前数据。替换前的数据会保留为数据目录旁的 `V2.before-import` 回滚副本。

迁移包包含大量本地内容，未使用独立密码加密，请只保存到可信位置。AI API Key 仍由 Windows 当前用户的 DPAPI 保护：迁移到另一 Windows 用户或电脑后，可能需要重新填写 API Key。

## 15. 常见问题

### 复制后没有新条目

确认“列表更新”已开启，复制内容不是空白，且相同内容没有被去重。图片还需要启用“支持图片”。

### 单击条目没有粘贴到目标应用

先让目标应用获得焦点，再打开或使用 SuperCV。检查目标应用是否允许自动粘贴，以及剪贴板是否被其他程序占用。

### 找不到较早内容

普通列表可能已达到条目上限。打开“设置 > 历史记录”查询；若当时未启用长久存储，该条目可能已经被淘汰。

### 图片无法预览或导出

确认图片支持已开启，原缓存文件没有被外部删除。也可以使用“看图片”交给 Windows 默认应用打开。

### AI 或 Agent 按钮不可用

确认 AI 总开关、API Key、接口地址和模型名正确，并通过连接测试。图片条目不支持 Agent 内容读取。

### Agent 重复调用工具

单次任务会在 12 轮后自动停止。可以缩小问题范围、指定 GUID 或显示序号，并重新发起请求。

### 审核批准没有执行修改

只有确认弹窗返回“确认”才会执行。取消后 Agent 会收到 `approval_rejected`，并可能改用只读方式完成任务。

### 关闭窗口后程序仍在运行

这是托盘模式。通过系统托盘选择“退出”，或启用“关闭应用直接退出”。

## 16. 恢复与维护

设置中的恢复默认值通常不删除普通条目、书签和历史，但会重置界面、快捷键、AI 和常用选项；API Key 是否清除以确认提示为准。执行任何清空、删除工作区或图片清理前，先确认当前工作区并备份重要内容。
